# Learning Roadmap

This roadmap combines the course sequence with a progressive subject-learning path. The course lesson notes and subject chapters serve different purposes: lesson notes preserve the course context; subject chapters provide the complete reusable reference.

## Phase 1 — Core Python

Study:

- Introduction, syntax, variables, and data types
- Strings and operators
- Conditional statements and loops
- Lists, tuples, dictionaries, and sets
- Functions, modules, packages, and virtual environments

**Practice outcome:** Build small command-line utilities that validate input, process collections, and produce useful output.

## Phase 2 — Robust Python scripts

Study:

- File and directory operations
- Exceptions and logging
- Command-line interfaces
- Configuration and environment variables
- Debugging and testing

**Practice outcome:** Build reliable scripts that inspect files, parse logs, and report operational status.

## Phase 3 — Linux and networking automation

Study:

- Linux scripting environment
- File permissions and ownership
- Processes and system information
- Client-server fundamentals
- HTTP, REST APIs, JSON, and Flask

**Practice outcome:** Automate repeatable Linux checks and interact with web services.

## Phase 4 — Cloud and integrations

Study:

- Boto3 and AWS authentication
- EC2, S3, EBS, Lambda, and CloudWatch
- GitHub and Jira APIs
- Webhooks and event-driven workflows

**Practice outcome:** Build cloud automation and a secured GitHub–Jira integration.

## Phase 5 — AIOps and projects

Study:

- Structured log processing
- Pandas
- Feature engineering
- Isolation Forest
- Model evaluation and alerting

**Practice outcome:** Build an anomaly-detection prototype and evaluate its false-positive behavior.

## Recommended study method

For each subject:

1. Read the chapter and understand the terminology.
2. Run each example in a disposable lab environment.
3. Modify the example and test edge cases.
4. Complete the exercises without copying the solution.
5. Record errors and troubleshooting steps.
6. Link the finished work to a practical project.
