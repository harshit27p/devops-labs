## Learning outcomes
- Run Python scripts and explain the role of the interpreter.
- Use readable names, indentation, functions, and imports.
- Work with built-in types and convert input safely.
- Implement conditions, loops, and command-line input.

Recommended: Python 3.10 or later. Create a virtual environment before installing third-party packages:

```bash
python -m venv .venv
# Linux/macOS
source .venv/bin/activate
# Windows PowerShell
.venv\Scripts\Activate.ps1
```

The examples in this section use the standard library.
