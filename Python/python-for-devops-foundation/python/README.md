# Python for DevOps

A practical Python learning and reference hub focused on Linux administration, cloud automation, APIs, infrastructure operations, and AIOps.

This documentation lives inside the [`devops-labs`](https://github.com/harshit27p/devops-labs) repository. It combines a course-based learning path with subject-wise reference notes and practical projects.

## Learning paths

| Path | Purpose |
|---|---|
| [Course roadmap](01-course-roadmap/README.md) | Follow the supplied Abhishek Veeramalla course sequence and lesson notes |
| Python fundamentals | Learn Python syntax, data types, control flow, and collections |
| Programming concepts | Functions, modules, packages, OOP, libraries, and environments |
| Linux and system automation | Work with files, permissions, processes, logs, and scheduled tasks |
| Networking and web automation | Client-server concepts, HTTP, REST APIs, Flask, and webhooks |
| Security and plugin development | Secure coding, authorized security labs, defensive analysis, and plugins |
| AWS and cloud automation | Automate AWS resources using Boto3 |
| AIOps | Process operational logs and explore anomaly detection |
| Practical projects | Apply concepts through complete, documented implementations |
| Python reference | Quick syntax, library, and troubleshooting references |

## Repository principles

1. **One detailed explanation per concept.** Course notes summarize the lesson and link to the authoritative subject chapter.
2. **Runnable examples.** Code samples should state prerequisites, inputs, expected behavior, and cleanup steps where relevant.
3. **DevOps context.** Examples should use realistic Linux, networking, cloud, CI/CD, and observability scenarios.
4. **Safe defaults.** Use least privilege, validate inputs, protect credentials, and make destructive cloud operations opt-in.
5. **No invented course content.** Only lessons supported by supplied course material are described as course coverage. Additional material is labelled as an extension.

## Suggested learning sequence

1. Python fundamentals and data structures.
2. Functions, modules, packages, and object-oriented programming.
3. Linux scripting, file handling, and automation.
4. Networking, web services, APIs, and webhooks.
5. AWS automation with Boto3.
6. AIOps and intelligent monitoring.
7. End-to-end practical projects.
