# Object-Oriented Programming

Object-oriented programming (OOP) models related state and behavior using classes and objects.

## Chapters
1. [Classes and Objects](01-classes-and-objects.md)
2. [OOP Principles](02-oop-principles.md)
3. [Composition, Inheritance, and Polymorphism](03-composition-inheritance-polymorphism.md)
4. [Practical Infrastructure Model](04-practical-infrastructure-model.md)

## Learning outcomes
- Define classes and instantiate objects.
- Encapsulate state and behavior.
- Choose composition or inheritance appropriately.
- Build small, testable models of infrastructure resources.

Use OOP when it improves organization. A short one-off script may be clearer with functions and dictionaries.
