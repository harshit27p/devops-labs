# Linux System Automation with Python

Use Python's standard library to inspect filesystems, run approved commands, and collect host information. Prefer established tools such as Ansible or configuration management for large-scale fleet changes.

## Safety
Examples are designed for local learning and read-only inspection unless clearly stated. Test changes in a disposable VM, back up important files, and use least privilege.
