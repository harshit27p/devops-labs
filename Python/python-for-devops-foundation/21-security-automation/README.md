# 21 — Security Automation

Build defensive scripts that reduce repetitive security work while preserving safety, auditability and human approval.

## Chapters
1. Secure Python coding principles
2. Input validation and output encoding
3. Safe subprocess execution
4. File integrity and hashing
5. Secrets and configuration hygiene
6. Defensive host checks

## Lab
Create a read-only host security snapshot: Python version, platform, selected file permissions, installed package metadata and listening-socket inventory where supported. Avoid collecting secrets or changing system state.
