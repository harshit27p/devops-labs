# AIOps Concepts and Use Cases

AIOps applies analytics and machine-learning techniques to operational telemetry to help detect patterns, correlate events and prioritize investigation.

## Common use cases
- Unusual error-rate or latency patterns
- Log event volume changes
- Alert correlation and deduplication
- Capacity trend analysis
- Incident context summarization

## Limits
- Anomaly is not synonymous with failure.
- Models can learn unhealthy baselines.
- Deployments and traffic seasonality change patterns.
- Poor telemetry creates poor results.
- Automated remediation can amplify an incident.

Keep an operator in the loop for consequential actions.
