# Python Environments and Dependencies

Reproducible environments prevent dependency conflicts between projects and make automation easier to deploy.

## Chapters
1. [Virtual Environments](01-virtual-environments.md)
2. [pip and Dependency Management](02-pip-and-dependency-management.md)
3. [Configuration and Secrets](03-configuration-and-secrets.md)

## Learning outcomes
- Create and activate isolated environments.
- Install and inspect packages using the correct interpreter.
- Record and reproduce dependencies.
- Separate application configuration from source code.
- Handle credentials using appropriate secret-management mechanisms.
