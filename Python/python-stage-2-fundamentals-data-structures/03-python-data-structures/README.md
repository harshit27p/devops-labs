## Choosing a structure

| Structure | Ordered | Mutable | Duplicates | Typical use |
|---|---:|---:|---:|---|
| String | Yes | No | Characters can repeat | Text and logs |
| List | Yes | Yes | Yes | Ordered inventory |
| Tuple | Yes | No | Yes | Fixed sequence |
| Dictionary | Insertion order preserved | Yes | Keys unique | Structured resource data |
| Set | No positional indexing | Yes | No | Uniqueness and membership |
